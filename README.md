# Пости для Instagram

Проста офлайн-апка: обираєш фото, обираєш текст, ставиш формат — і завантажуєш готовий PNG.

## Як запустити

**На комп'ютері:** двічі клікнути на `index.html`. Все, інтернет не потрібен.

**На телефоні:** запустити в терміналі

```bash
./tools/serve.sh
```

і відкрити на телефоні адресу, яку покаже скрипт (телефон і Mac — в одному Wi-Fi).

## Як користуватись

1. **Фото** — клікни на мініатюру (наведи, щоб побачити опис). Під галереєю —
   опис вибраного фото. Можна додати своє через «+ Своє фото».
2. **Формат** — 1:1, 4:5, 3:4, 9:16, 1.91:1, 16:9.
3. **Кадрування** — тягни фото мишкою, колесо миші або повзунок «Масштаб».
4. **Затемнення** — градієнт під текстом, щоб букви читались на світлому фото.
5. **Свій текст — авто** — вписуєш текст, тиснеш «✨ Підібрати вигляд», і апка сама
   добирає стиль, колір і розташування під вибране фото (див. нижче).
6. **Готові тексти** — клік по картці підставляє заголовок і підпис. Під списком
   з'являється підказка «Пасує до тексту» — фото, які підходять за змістом
   (напр. «ВОДА Є ЗАВЖДИ» → зона мийок). Клік по підказці ставить це фото.
   Кнопки «← попередній / наступний →» під фото гортають усі 10 текстів.
   Кнопка «+ свій текст» прибирає готовий текст і дає порожній шаблон;
   якщо готового тексту вже немає — додає ще один рядок.
7. **Стиль тексту** — 12 готових стилів (див. нижче). Один клік міняє шрифт,
   колір, затемнення й розташування одразу.
8. **Розкладка** — вгорі / по центру / внизу.
9. **Шари тексту** — шрифт, розмір, колір, вирівнювання, тінь, обведення, підкладка.
   Текст можна тягати мишкою прямо по фото, стрілки на клавіатурі — точне зміщення.

## Автопідбір вигляду

Кнопка **🎲 Інший вигляд** прямо під фото. Тиснеш — і апка добирає до цього фото
стиль, колір, затемнення й розташування тексту. **Фото не змінюється і не зсувається** —
воно ваше, міняється тільки оформлення тексту.

Якщо треба одразу свій текст: впиши його в «Свій текст — авто» (перший рядок —
заголовок, далі підпис) і натисни «✨ Підібрати вигляд».

Підбір не сліпий. Апка аналізує **саме той кадр, який ви бачите** (з урахуванням
формату й кадрування), і для кожної пари «стиль × розташування» рахує:

- **яскравість і рівність фону точно в тому прямокутнику**, куди ляже текст —
  не «нижня третина», а реальна ділянка з урахуванням довжини рядків і вирівнювання;
- **як затемнення чи плашка стилю освітлюють цю ділянку**, і який після цього контраст;
- **чи не вилазить текст за край** кадру;
- **довжину заголовка** — довгий не потрапить у стиль з величезним шрифтом.

Акцентний колір теж береться **з фото**: апка рахує гістограму відтінків кадру.
Основний колір ваших інтер'єрів — тепла пісочна (37.5°, `#deb673`); якщо в кадрі
є другий помітний колір, інколи береться він (напр. рожева картина на фото 2 —
`#de739b`). **Холодні відтінки (160°–280°) відкидаються** — небо у вікні на фото
з терасою не стає акцентом, бо випадало б з теплої гами салону. Резервна палітра
теж тільки тепла: золото, пісочна, кремова, біла.

Затемнення їде разом з текстом: якщо текст переїхав угору, градієнт теж.

Обмежень немає — випасти може будь-яка комбінація, просто ті, що краще пасують
до фото, випадають частіше. Поточний варіант завжди пропускається, тож кнопка
ніколи не спрацьовує «вхолосту».

Далі будь-що можна поправити руками — автопідбір лише ставить стартову точку.

## Стилі тексту

Найходовіші в SMM формати підпису на фото:

| Стиль | Коли брати |
|---|---|
| **Класика** | універсальний: градієнт знизу, білий жирний текст |
| **Субтитри** | як у Reels — чорна плашка під текстом, добре читається на будь-якому фото |
| **Хайлайт** | заголовок на кольоровій плашці — акцент, акції, набір |
| **Обведення** | білий текст з контуром, працює навіть без затемнення |
| **Капси** | великі літери по центру, все фото затемнене — гучне оголошення |
| **Біла картка** | текст на білій плашці — оголошення, вакансія, прайс |
| **Мінімал** | тонкий шрифт з широкою розрядкою — преміум-б'юті |
| **Журнал** | serif-заголовок зверху — фешн, естетика |
| **Ліворуч** | вирівняно по лівому краю знизу — лаконічно |
| **Золото** | заголовок акцентним кольором |
| **М'який** | теплий serif, кремовий колір, м'яке затемнення |
| **Сторіс** | текст угорі — щоб не перекривався кнопками Instagram у Stories |

Стиль можна взяти за основу й далі підкрутити вручну в «Шари тексту».

Зверху праворуч — роздільність (1080 / 1440 / 2160 px по ширині) і кнопка збереження.

## На телефоні

Інтерфейс перебудовується: фото зверху, під ним чотири вкладки — **Фото · Формат · Текст · Стиль**.

- фото пересувається пальцем, масштаб — щипком двома пальцями;
- текст так само тягається пальцем;
- кнопка «↓ Зберегти» відкриває системне «Поділитися» — звідти можна зберегти
  в Фото або одразу відправити в Instagram.

## Як змінити фото

Поклади нові файли в папку `photos/` і запусти:

```bash
./tools/build-photos.sh
```

Скрипт стисне їх і перезбере `photos.js`. Оновити сторінку в браузері.

Описи фото (`desc`) скрипт **переносить** зі старої збірки за іменем файлу, тож
перезбірка їх не стирає. Нове фото отримує порожній `desc` — впишіть його вручну.

## Як змінити тексти

Відредагуй `texts.js` — там масив блоків `{ emoji, title, body, photos }`.
`photos` — список id фото, які пасують до тексту (звідки береться підказка).
`\n` у рядку — примусовий перенос; без нього текст переноситься сам по ширині.

## Файли

| Файл | Що це |
|---|---|
| `index.html` | вся апка (інтерфейс + рендер + експорт) |
| `photos.js` | фото, вшиті як base64 + опис кожного (`desc`) |
| `texts.js` | бібліотека текстів |
| `photos/` | оригінали фото |
| `tools/build-photos.sh` | перезбирає `photos.js` з `photos/` |
| `tools/serve.sh` | локальний сервер, щоб відкрити з телефона |
